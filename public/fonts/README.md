# Editorial font assets

Self-hosted Latin variable WOFF2 subsets, used by the opt-in editorial Work
presentation. No third-party font requests or JavaScript font loader.

- Newsreader: Fontsource variable package 5.2.8, `newsreader-latin-wght-normal.woff2`
  (<https://cdn.jsdelivr.net/npm/@fontsource-variable/newsreader@5.2.8/files/newsreader-latin-wght-normal.woff2>).
- Inter: Fontsource variable package 5.2.8, `inter-latin-wght-normal.woff2`
  (<https://cdn.jsdelivr.net/npm/@fontsource-variable/inter@5.2.8/files/inter-latin-wght-normal.woff2>).

Both are SIL Open Font License 1.1; the respective notices are included beside
the fonts. System fallbacks and `font-display: swap` keep content readable while
fonts load. Normal/upright styles only; no font-package runtime dependency.

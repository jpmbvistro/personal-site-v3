Keel is a standalone, repository-agnostic build harness for agentic engineering. The goal is to connect authorized GitHub issues with independently verified draft pull requests while keeping the coding agent responsible for engineering reasoning.

## An explicit handoff

The supervisor admits an issue, creates an isolated worktree, and starts a fresh agent runtime. A durable typed contract records the builder's handoff.

The current implementation stops at awaiting verification. Verification, review, and publication orchestration remain future stages; the intended workflow is not a claim of complete autonomous delivery.
